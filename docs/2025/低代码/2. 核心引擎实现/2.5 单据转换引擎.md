# 2.5 单据转换引擎

## 2.5.1 概述

### 业务场景与价值

单据转换引擎是低代码平台中实现**跨系统数据流转**的核心组件，主要解决以下业务问题：

- **异构系统集成**：不同业务系统间的数据格式差异转换
- **流程单据流转**：业务流程中不同节点间的单据格式适配
- **数据标准化**：将非标准数据转换为统一格式

### 架构定位

单据转换引擎作为**独立核心引擎**，与其他引擎松耦合：

```
┌─────────────────────────────────────────────────────────────────┐
│                      单据转换引擎                               │

│  │ 规则管理模块  │───▶│ 表达式引擎   │───▶│ 执行引擎     │    │
│  │ (RuleManager)│    │ (Expression  │    │ (Executor)   │    │
│  │              │    │   Engine)    │    │              │    │
│  └──────┬───────┘    └──────┬───────┘    └──────┬───────┘    │
```

## 2.5.2 转换规则规则定义

### 规则Schema设计

```xml
<?xml version="1.0" encoding="UTF-8"?>
<conversion-package xmlns="http://lowcode.platform/conversion"
                   id="com.crm.conversion"
                   version="1.0.0">

  <!-- 数据源实体引用 -->
  <references>
    <reference entity="com.crm.purchase.Customer" />
    <reference entity="com.sales.Order" />
    <reference entity="com.inv.Delivery" />
  </references>

  <!-- 转换规则定义 -->
  <rules>
    <!-- 采购订单 → 销售订单 -->
    <rule id="com.crm.purchase.toSalesOrder" 
          name="采购转销售"
          source="com.crm.purchase.Customer"
          target="com.sales.Order"
          version="1.0">
      
      <!-- 转换条件（可选） -->
      <condition expression="source.status == 'ACTIVE'" />
      
      <!-- 字段映射列表 -->
      <mappings>
        <!-- 直接映射 -->
        <mapping sourceField="id" targetField="customerId" />
        
        <!-- 表达式映射 -->
        <mapping sourceField="customerCode" targetField="orderNo">
          <transform expression="concat('SO-', source)" />
        </mapping>
        
        <!-- 常量映射 -->
        <mapping targetField="status">
          <constant value="PENDING" />
        </mapping>
        
        <!-- 默认值映射 -->
        <mapping sourceField="creditLimit" targetField="amount">
          <default value="0" />
        </mapping>
        
        <!-- 关联字段映射（支持嵌套属性） -->
        <mapping sourceField="buyerId.name" targetField="salesName" />
      </mappings>
      
      <!-- 后置动作 -->
      <post-actions>
        <action type="VALIDATE" expression="target.amount > 0" errorMessage="金额必须大于0" />
        <action type="CALCULATE" targetField="profit" expression="target.amount * 0.2" />
      </post-actions>
    </rule>
    
    <!-- 销售订单 → 出库单 -->
    <rule id="com.sales.order.toDelivery"
          name="订单转出库"
          source="com.sales.Order"
          target="com.inv.Delivery"
          version="1.0">
      <mappings>
        <mapping sourceField="orderNo" targetField="deliveryNo" />
        <mapping sourceField="warehouseId" targetField="warehouseId" />
        <mapping sourceField="quantity" targetField="quantity" />
      </mappings>
    </rule>
  </rules>

</conversion-package>
```

### Schema元素说明

| 元素 | 属性 | 说明 |
|-----|------|-----|
| `conversion-package` | `id`, `version` | 转换规则包根元素 |
| `references` | - | 引用的实体列表 |
| `reference` | `entity` | 引用的实体ID |
| `rules` | - | 转换规则集合 |
| `rule` | `id`, `name`, `source`, `target`, `version` | 转换规则定义 |
| `condition` | `expression` | 转换前置条件 |
| `mappings` | - | 字段映射集合 |
| `mapping` | `sourceField`, `targetField` | 字段映射定义 |
| `transform` | `expression` | 转换表达式 |
| `constant` | `value` | 常量值 |
| `default` | `value` | 默认值 |
| `post-actions` | - | 后置动作集合 |
| `action` | `type`, `expression`, `errorMessage` | 动作定义（VALIDATE/CALCULATE） |

## 2.5.3 转换引擎架构

### 核心组件

| 组件 | 职责 | 说明 |
|-----|------|------|
| **RuleManager** | 规则管理 | 加载、存储、查询转换规则 |
| **ExpressionEngine** | 表达式计算 | 执行SpEL/MVEL表达式 |
| **FieldMapper** | 字段映射 | 执行字段级别的转换 |
| **ActionExecutor** | 动作执行 | 执行后置验证和计算 |
| **MetadataRefResolver** | 元数据引用解析 | 解析实体ID对应的字段定义 |

### 转换流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                        转换执行流程                                │
├─────────────────────────────────────────────────────────────────────┤
│  1. 获取规则         2. 验证条件          3. 执行字段映射         │
│     ▼                    ▼                     ▼                  │
│  RuleManager ──────▶ Condition ──────▶ FieldMapper               │
│                          │                     │                  │
│                          ▼                     ▼                  │
│                   [条件不满足]            [执行表达式]             │
│                          │                     │                  │
│                          ▼                     ▼                  │
│                    抛出异常              4. 执行后置动作           │
│                                              ▼                   │
│                                         PostActionExecutor        │
│                                              │                   │
│                                              ▼                   │
│                                         5. 返回结果               │
└─────────────────────────────────────────────────────────────────────┘
```

### 错误处理机制

- **验证异常**：条件不满足或数据校验失败时抛出 `ConversionValidationException`
- **映射异常**：字段映射失败时抛出 `FieldMappingException`
- **表达式异常**：表达式执行失败时抛出 `ExpressionEvaluationException`
- **日志记录**：记录完整的转换过程，便于问题排查

```java
/**

public interface DocumentConversionEngine {
    
    /**
     * 执行单据转换

     * 根据源和目标实体获取转换规则
     * @param sourceEntityId 源实体ID
     * @param targetEntityId 目标实体ID

    ConversionRule findRule(String sourceEntityId, String targetEntityId);

     * 加载转换规则包

    /**
     * 热更新指定规则
     * @param ruleId 规则ID
     * @param rule 新的规则定义
     */
    void reloadRule(String ruleId, ConversionRule rule);
```

### 转换流程代码示例

```java
/**
 * 单据转换引擎实现
 */
public class DocumentConversionEngineImpl implements DocumentConversionEngine {
    
    private RuleManager ruleManager;
    private ExpressionEngine expressionEngine;
    private MetadataRefResolver metadataResolver;
    
    @Override
    public Map<String, Object> convert(Map<String, Object> sourceData, String ruleId) {
        // 1. 获取规则
        ConversionRule rule = ruleManager.getRule(ruleId);
        if (rule == null) {
            throw new ConversionException("转换规则不存在: " + ruleId);
        }
        
        // 2. 验证前置条件
        if (rule.getCondition() != null && !expressionEngine.evaluate(rule.getCondition(), sourceData)) {
            throw new ConversionValidationException("转换条件不满足");
        }
        
        // 3. 执行字段映射
        Map<String, Object> targetData = new HashMap<>();
        for (FieldMapping mapping : rule.getMappings()) {
            Object value = resolveFieldValue(sourceData, mapping);
            targetData.put(mapping.getTargetField(), value);
        }
        
        // 4. 执行后置动作
        executePostActions(targetData, rule.getPostActions());
        
        return targetData;
    }
    
    /**
     * 解析字段值
     */
    private Object resolveFieldValue(Map<String, Object> sourceData, FieldMapping mapping) {
        // 常量映射
        if (mapping.getConstantValue() != null) {
            return mapping.getConstantValue();
        }
        
        // 源字段映射
        Object sourceValue = getNestedValue(sourceData, mapping.getSourceField());
        
        // 默认值处理
        if (sourceValue == null && mapping.getDefaultValue() != null) {
            return mapping.getDefaultValue();
        }
        
        // 表达式转换
        if (mapping.getTransformExpression() != null && sourceValue != null) {
            Map<String, Object> context = new HashMap<>();
            context.put("source", sourceValue);
            return expressionEngine.evaluate(mapping.getTransformExpression(), context);
        }
        
        return sourceValue;
    }
    
    /**
     * 获取嵌套属性值
     */
    private Object getNestedValue(Map<String, Object> data, String fieldPath) {
        String[] parts = fieldPath.split("\\.");
        Object current = data;
        for (String part : parts) {
            if (current instanceof Map) {
                current = ((Map<?, ?>) current).get(part);
            } else {
                // 通过反射获取对象属性
                try {
                    java.lang.reflect.Field field = current.getClass().getDeclaredField(part);
                    field.setAccessible(true);
                    current = field.get(current);
                } catch (Exception e) {
                    return null;
                }
            }
            if (current == null) break;
        }
        return current;
    }
    
    /**
     * 执行后置动作
     */
    private void executePostActions(Map<String, Object> targetData, List<PostAction> actions) {
        if (actions == null) return;
        
        for (PostAction action : actions) {
            switch (action.getType()) {
                case VALIDATE:
                    boolean isValid = expressionEngine.evaluate(action.getExpression(), targetData);
                    if (!isValid) {
                        throw new ConversionValidationException(action.getErrorMessage());
                    }
                    break;
                case CALCULATE:
                    Object result = expressionEngine.evaluate(action.getExpression(), targetData);
                    targetData.put(action.getTargetField(), result);
                    break;
                case LOG:
                    // 记录日志
                    log.info("转换日志: {}", expressionEngine.evaluate(action.getExpression(), targetData));
                    break;
            }
        }
    }
}
```

## 2.5.5 应用场景

### 场景一：跨系统单据转换

**业务背景**：采购系统的采购订单需要转换为销售系统的销售订单

```xml
<rule id="com.crm.purchase.toSalesOrder"
      name="采购转销售"
      source="com.crm.purchase.Customer"
      target="com.sales.Order">
  <mappings>
    <mapping sourceField="customerCode" targetField="orderNo">
      <transform expression="concat('SO-', source)" />
    </mapping>
    <mapping sourceField="creditLimit" targetField="amount" />
    <mapping targetField="status" constant="PENDING" />
  </mappings>
</rule>
```

### 场景二：流程节点单据适配

**业务背景**：审批流程中，审批通过后需要将申请单转换为工单

```xml
<rule id="com.approval.request.toWorkOrder"
      name="申请转工单"
      source="com.approval.Request"
      target="com.workflow.WorkOrder">
  <condition expression="source.status == 'APPROVED'" />
  <mappings>
    <mapping sourceField="id" targetField="requestId" />
    <mapping sourceField="applicantId" targetField="assigneeId" />
    <mapping sourceField="title" targetField="title" />
    <mapping sourceField="priority" targetField="priority" />
  </mappings>
  <post-actions>
    <action type="CALCULATE" targetField="dueDate" expression="now().plusDays(3)" />
  </post-actions>
</rule>
```

### 场景三：数据格式标准化

**业务背景**：外部系统的数据格式需要转换为内部标准格式

```xml
<rule id="com.external.crm.toInternal"
      name="外部CRM转内部"
      source="com.external.Customer"
      target="com.internal.Customer">
  <mappings>
    <!-- 字段重命名 -->
    <mapping sourceField="CUST_NAME" targetField="name" />
    <mapping sourceField="CUST_EMAIL" targetField="email" />
    
    <!-- 数据格式转换 -->
    <mapping sourceField="CUST_PHONE" targetField="phone">
      <transform expression="replaceAll(source, '[^\\d]', '')" />
    </mapping>
    
    <!-- 枚举值映射 -->
    <mapping sourceField="CUST_STATUS" targetField="status">
      <transform expression="source == '1' ? 'ACTIVE' : 'INACTIVE'" />
    </mapping>
  </mappings>
</rule>
```
