# 低代码平台设计文档

### 什么是低代码
```
低代码（Low-Code）是由Forrester Research在2014年正式提出的可视化软件开发方式，核心是通过图形化拖拽、参数配置替代传统手写代码，仅需少量编码即可快速构建并部署应用程序。
它同时面向两类人群：无专业开发经验的业务人员（平民开发者）可自助搭建轻量应用，专业开发者也能通过它提升研发效率，相比传统开发能将交付周期从数月压缩到数天，显著降低开发成本。
```

### 低代码的典型使用场景
```
低代码更适配流程清晰、数据结构稳定、需快速迭代的场景，典型场景包括：

企业内部流程与办公工具
这是低代码最普遍的应用场景，比如办公审批、费用报销、采购合同管理、项目协作等。业务人员可自主配置流程，IT仅需负责权限与合规管控，能快速响应部门个性化需求，避免需求排队等待开发。

数据采集与轻量业务管理
支持快速构建移动端表单、门店巡检、生产质检、设备台账、客户线索管理（轻量CRM）、售后工单等应用，适配一线业务快速变动的需求，无需从零开发就能快速调整。

跨系统集成与运营自动化
低代码平台内置丰富连接器，可以可视化编排对接企业现有ERP、OA、CRM、财务系统，实现跨系统自动化流程，比如订单创建后自动校验库存、触发审批、同步数据并通知客户，减少重复人工操作。

快速搭建前端应用与数据展示
可以快速开发企业门户、运营活动H5、小程序、数据大屏、业务分析看板，支持运营人员快速做A/B测试和需求迭代，适合需要快速验证的增长实验场景。
```

### 低代码不适合以下情况：
```
超高并发、极致性能要求的系统（如高频交易、大型游戏后端）
高度定制化算法（如 AI 模型训练、复杂图形渲染）
强安全合规且架构极度复杂的金融核心系统
```
