# 低代码平台设计文档

### 什么是低代码
```
低代码（Low-Code）是一种可视化软件开发方式，核心是通过图形化拖拽、参数配置替代传统手写代码，仅需少量编码即可快速构建并部署应用程序。
它同时面向两类人群：无专业开发经验的业务人员（平民开发者）可自助搭建轻量应用，专业开发者也能通过它提升研发效率，相比传统开发能将交付周期从数月压缩到数天，显著降低开发成本。
```

### 低代码的典型使用场景
```
低代码更适配流程清晰、数据结构稳定、需快速迭代的场景，典型场景包括：

1. 企业内部管理系统
OA 办公、审批流程、人事管理、CRM、ERP 模块等标准化程度高的系统。企业无需为每个模块从零开发。
2. 数据收集与报表
快速搭建问卷调查、数据填报、可视化仪表盘，替代 Excel 协作的混乱。
3. 业务流程自动化
跨系统的简单流程编排，如"订单触发 → 通知仓库 → 更新财务"，通过可视化工作流实现。
4. 移动应用/小程序
营销活动页、内部工具类小程序、简单的电商展示页面。
5. 原型验证与 MVP 开发
创业公司快速验证商业想法，先上线再迭代，避免前期投入大量研发成本。
6. 遗留系统现代化改造
为老旧系统快速搭建新界面或补充模块，作为过渡方案。
```

### 低代码不适合以下情况：
```
超高并发、极致性能要求的系统（如高频交易、大型游戏后端）
高度定制化算法（如 AI 模型训练、复杂图形渲染）
强安全合规且架构极度复杂的金融核心系统
```
